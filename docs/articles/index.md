# Articles

These guides are written for building experiments with `trackflow`. Read them
in order when you are learning the package, or jump to the page that matches
what you need right now.

## Start here

- [Start a project and make a lab copy](start-project-lab-copy.md): create a
  project, add an experiment scaffold, run it locally, and package it for a lab
  computer.

## Build the experiment

- [Understand the timeline](understand-timeline.md): create stimuli, make
  screens, group screens into trials, and run them from Python.
- [Create custom stimulus functions](custom-stimulus-functions.md): organize
  task-specific visual builders in `stimuli.py`.
- [Use screen hook functions](screen-hook-functions.md): send markers, check
  gaze, and edit rows at screen events.
- [Understand timeline data](timeline-data.md): see what the timeline records
  automatically and create optional trial summaries with `data_format`.

## Add devices and deployment details

- [Add EEG and eye tracking later](eeg-eye-tracking.md): connect EEG markers
  and EyeLink support after the behavior task works.
